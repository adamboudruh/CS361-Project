# CS361-Project

This is the repository for my final project in CS361.

## Overview

This project is a Python-based application with a text-based UI thates focus on compiling information about your favorite NBA teams or Players and converting NBA Player Portraits to ASCII art.

## Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/adamboudruh/CS361-Project.git
   cd CS361-Project
   ```

2. **(Optional) Set up a virtual environment:**
   ```bash
   python -m venv env
   source env/bin/activate  # On Windows: env\Scripts\activate
   ```

3. **Install dependencies:**
   - For Linux:
     ```bash
     pip install lxml-5.3.1-pp310-pypy310_pp73-manylinux_2_28_x86_64.whl
     ```
   - For Windows:
     ```bash
     pip install lxml-5.3.1-pp310-pypy310_pp73-win_amd64.whl
     ```

4. **Run the project:**
   ```bash
   python main.py
   ```
